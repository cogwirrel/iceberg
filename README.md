## Fork Notes

This is a fork of [Apache Iceberg](https://github.com/apache/iceberg/) which backports the [Dynamic Iceberg Flink Sink](https://github.com/apache/iceberg/pull/12424) to Iceberg 1.8.1 and Flink 1.20.0.

This allows for it to be used in [Amazon Managed Service for Apache Flink](https://aws.amazon.com/managed-service-apache-flink/).

Note: this fork is not maintained and is for demo purposes only. Use at your own risk.
